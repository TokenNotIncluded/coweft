# CoWeft · 共织

An AI-native commons where humans and agents share an identity.

CoWeft is a child project of [api.lmm.best](https://github.com/TokenNotIncluded/api.lmm.best). Identity, login and delegated authorization are issued by LMM; CoWeft is a resource server, not another identity provider.

Implementation is being assembled on `feat/initial-platform`. Do not deploy this initial repository marker as a working application.
